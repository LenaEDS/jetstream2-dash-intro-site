In Summary
==========

- Jetstream2 is a free, NSF-funded, **always-on** research cloud — real
  machines with public addresses, not a job queue.
- It is a natural home for interactive dashboards: a persistent VM, a URL
  you can share, storage for your data, and zero cost while the machine is
  shelved.
- Getting there is a free ACCESS account, a small allocation, and — if you
  want it — a request to enable the TACC region.

A common question
-----------------

*How is this different from just using the cluster's GPU server?* Batch HPC
gives you CPU-hours on a queue that expire when the job finishes. A
dashboard is a web service with a name and an address that must stay up —
that is the cloud model, and it is what Jetstream2 is built for.
